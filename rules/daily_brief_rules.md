## 1. 总体目标

每天生成中文简报，固定覆盖：
1. 人工智能与科技
2. 比特币与加密市场
3. 宏观经济与投资
4. 国内外重大新闻

要求：优先筛选最近24小时真正重要的新进展；提供事实、趋势与影响分析、投资利好/利空判断、可实际使用的工具与机会；避免信息堆砌；明确区分事实、分析、推测。

所有新鲜数据尽量使用可靠、可验证来源并标注日期/时间。某项数据无法可靠取得时，明确写“未取得可靠值”，不得猜测，也不得沿用旧值冒充当天值。

## 2. BTC核心指标

### 2.1 MVRV Ratio
长期估值主指标。报告最新可靠数值、区间及历史含义，回答“BTC相对链上成本基础总体偏贵还是偏便宜？”

### 2.2 STH-MVRV
短中期持有人状态指标。说明短期持有人整体浮盈、平衡或浮亏；1.0为关键枢轴。

### 2.3 AHR999
长期定投/极端估值辅助指标，不单独作为买卖信号。

取数优先级：
1. AIX4U AHR999 Dataset 最新完整日线
2. 项目 GitHub 原始 JSON/CSV
3. Hugging Face 镜像
4. 9992100.xyz 实时接口仅辅助参考

必须标注 UTC 日期/时间、来源、数值、区间，并尽量报告 quantile5y。

参考区间：
- <0.45：历史低估/价值区
- 0.45–1.20：定投区
- 1.20–3：谨慎
- >3：泡沫风险

### 2.4 美国现货BTC ETF Flow
观察机构真实资金。报告最近完整美国交易日数据；当天数据不完整必须标注；不得把缺失写成0；优先看连续性与多日累计。

### 2.5 BTC永续合约 Funding
观察杠杆情绪。

当前无 CoinGlass API Key 时：
- CoinGlass 网页仅人工核对。
- 日常取数优先官方交易所公开接口，至少 OKX，尽量加入 Binance、Bybit。
- 标注平台、数据时间、结算周期、当前/预计 Funding、上一期实际结算 Funding（若可得）。
- 单个平台失败时，改用其他官方源，不得让整个 Funding 项缺失。

统一尽量折算8小时：
- 0%–0.03%/8h：健康
- 0.03%–0.05%/8h：警惕/拥挤
- >0.05%/8h：明显过热

未来获得 CoinGlass API Key 后：主指标升级为 OI 加权 Funding；成交额加权 Funding 与 Binance/OKX/Bybit 作为交叉验证。

### 2.6 aSOPR
真实链上已实现盈亏指标。报告最新可靠值，优先同时观察7DMA。
- >1：平均盈利兑现
- ≈1：盈亏平衡/成本重置
- <1：平均亏损兑现

不因单日轻微偏离1机械下结论，重点看持续性与7DMA趋势。

### 2.7 SSR Oscillator
观察稳定币相对BTC的潜在购买力。优先使用 SSR Oscillator，不用原始SSR绝对值作为主判断。
- 0附近：平衡
- 负值：稳定币相对购买力更充足
- 正值：相对购买力减弱
- ±2附近：统计极端参考，不得机械交易

## 3. CVDD长期底部锚模块（固定新版）

目标同时回答两个问题：
1. 长期底部锚本身是否正在上移、横盘或回落？
2. BTC当前是在靠近这个底部锚，还是正在远离它？

### 3.1 数据口径
主口径：Glassnode PiT CVDD（Point-in-Time CVDD）。

普通 Glassnode CVDD、Bitbo 或其他公开来源仅用于交叉核对。禁止不同口径混合计算历史变化，也禁止不同数据源历史阈值混用。

每个CVDD数据必须标注：来源、对应日期/时间、是否为当日最新可靠值。

若公开页面只有缓存/延迟值或无法确认日期，不得写“今日最新CVDD”。应写“截至YYYY-MM-DD的最新可靠PiT CVDD为……”；无法确认则写“未取得可靠值”。不得沿用上一日数字冒充当天数据。

### 3.2 PiT CVDD本身：慢变量
固定展示：
- 当前最新可靠值
- 30日前值
- 90日前值

计算：
- 30D变化率 = 当前CVDD ÷ 30日前CVDD − 1
- 90D变化率 = 当前CVDD ÷ 90日前CVDD − 1

趋势判断：
- ↑ 底部锚上移
- → 基本横盘
- ↓ 底部锚回落

重点解释变化方向和速度，不夸大几美元/几十美元的单日变化，也不得仅因单日CVDD涨跌给出看多/看空结论。

### 3.3 Price/CVDD：主要距离指标
定义：Price/CVDD = BTC同期价格 ÷ PiT CVDD。

BTC价格与PiT CVDD尽量使用同一日期或最接近的统一时间口径。

固定展示：
- 当前 Price/CVDD
- 7日前 Price/CVDD
- 30日前 Price/CVDD

计算7D与30D变化率，并判断：
- 快速接近CVDD
- 缓慢接近CVDD
- 距离基本稳定
- 缓慢远离CVDD
- 快速远离CVDD

### 3.4 Price/CVDD固定监控区间
- >1.30：离历史极端底部仍有明显距离
- 1.15–1.30：重点观察区
- 1.05–1.15：历史重要底部区域
- ≤1.05：极端底部区域
- ≈1.00：接近或触及CVDD长期底部锚

这些区间仅用于历史监控与风险预警，不是机械买卖线。

历史校准优先参考2015、2018、2022三个完整周期底部；2020 COVID仅作为极端流动性冲击参考。

### 3.5 每月首份日报增加365D
每个月第一份日报额外展示：
- 当前 PiT CVDD
- 365日前 PiT CVDD
- 365D变化率

目的：观察过去一年长期底部锚整体抬升速度；无需每天重复。

### 3.6 CVDD固定输出结构
A. 底部锚趋势：当前/30日前/90日前PiT CVDD、30D/90D变化率、上移/横盘/回落判断。

B. BTC距CVDD：BTC同期价格、当前/7日前/30日前Price/CVDD、7D/30D变化率、接近/远离判断。

最后用一句话综合：底部锚自身趋势 + BTC相对底部锚距离趋势 + 当前所处Price/CVDD监控区间。

## 4. 宏观指标

### 4.1 布伦特原油
用于观察再通胀、地缘与流动性风险。参考：<90风险相对缓和；>100再通胀风险明显；>110宏观压力升级。具体判断结合事件背景，不机械使用阈值。

### 4.2 美国国债收益率
必要时加入，重点观察长期收益率对流动性、科技股估值、BTC风险偏好的影响。

## 5. 高价值候选/增强指标

### 5.1 LTH Sell-Side Risk Ratio
观察长期持有人是否大规模兑现。暂不强制每日；数据可靠时可做周度跟踪，或明显抬升、对顶部/分配风险有增量价值时加入。当值为估算时必须明确，不得伪装成官方精确值。

### 5.2 AVIV Ratio
仅在数据稳定可靠且有明显增量价值时加入。

### 5.3 Pi Cycle Top
保留候选库，不固定加入日报；仅在接近历史顶部形态并与其他指标形成共振时提及。

## 6. 综合判断原则

每个指标尽量回答不同问题，避免重复堆砌。当前维度覆盖：长期估值、短期持有人状态、真实兑现行为、稳定币购买力、机构资金、杠杆情绪、长期底部距离锚、长期持有人分配风险、宏观环境。

不得由单一指标决定结论。最终使用：🟢绿灯 / 🟡黄灯 / 🟠橙灯 / 🔴红灯，并说明原因。
